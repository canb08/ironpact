## Scope
1. `src/ui/tokens.css`: complete the §3.2 tokens (A1 started it) — dark default, light fallback under `[data-theme="light"]`, spacing/radius scale from §3.5, as CSS custom properties consumed by Tailwind 4 (`@theme`). No grain, no glass, no brushed steel yet.
2. Plain, accessible primitives in `src/ui/` (React 19, typed props, no `any`):
   - `Button.tsx` (primary/secondary/ghost; min target 48 px, `size="xl"` 64 px for workout controls);
   - `Stepper.tsx` (value ± step, long-press repeat optional, `aria-label`s, keyboard ±);
   - `HoldButton.tsx` (press-and-hold, default 600 ms, shows progress with a plain bar, cancels on release, keyboard: hold Space/Enter; `onHoldComplete`);
   - `Sheet.tsx` (bottom sheet, focus trap, Esc/close button, `aria-modal`);
   - `Toast.tsx` (queue, `aria-live="polite"`, optional action e.g. "Undo" with timeout);
   - `Chip.tsx`, `BigNumber.tsx` (tabular numerals).
   - `src/ui/index.ts` barrel export.
3. `src/ui/copy.ts`: **one exported object** holding every string from §3.10.1 verbatim (plus the Phase-1 strings named in spec §6 Phase 1, e.g. "Link delayed — try again in 60 s", "Code's dead. Ask for a new one.", "Saved on your phone. Syncs when you're back up."). Use `{me}`/`{partner}` placeholders and a typed `fill(template, vars)` helper. Names never appear in copy.
4. Tests (Vitest + Testing Library, jsdom):
   - `tests/unit/copy.test.ts`: banned words from §3.12 #3 (case-insensitive) never appear in `src/ui/copy.ts` **or** `supabase/functions/_shared/push-copy.ts` if it exists (E6.3); no string contains an email-like `@domain`; `fill()` replaces all placeholders and throws on a missing var.
   - `tests/unit/ui/*.test.tsx`: HoldButton fires only after the full hold (fake timers) and not on early release; Stepper clamps to min/max; Sheet traps focus and closes on Esc; Toast action fires and auto-dismisses.
   - Add whatever dev deps this needs (`@testing-library/react`, `@testing-library/user-event`, `jsdom`), exact versions, and record them in `docs/STACK.md`.
5. A dev-only route `/dev/ui` in `src/router.tsx` showing every primitive (this is the phone preview for this ticket). Exclude it from production builds (`import.meta.env.DEV`).
