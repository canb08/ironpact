## Scope
1. `public/_headers`: exactly the §4.7 header set with the E3.6 changes. CSP `connect-src` allows `https://*.supabase.co` and `wss://*.supabase.co`; `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Permissions-Policy`; long cache for hashed `/assets/*`; `no-cache` for `/`, `/index.html`, `/sw.js`, `/manifest.webmanifest`.
2. `scripts/gen-headers.mjs` only if §4.7/E3.6 needs a generated CSP (e.g. a hash of an inline script); otherwise skip it and say so in the PR.
3. SPA fallback: confirm Cloudflare Pages serves `index.html` for unknown paths without a `404.html` (R1 item 11). If not, add `public/_redirects` with `/* /index.html 200`.
4. `.github/workflows/keepalive.yml`: cron every 2 days → `curl -fsS "$HEALTH_URL"` (secret `HEALTH_URL`; when unset, print a notice and pass). A monthly step commits `heartbeat.txt` (one date line) so GitHub doesn't disable scheduled workflows (E3.9). `permissions: contents: write` only.
5. `heartbeat.txt` (one line) and `docs/DEPLOY.md`: exact human steps for Cloudflare Pages (build `npm run build`, output `dist`, env vars `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_BACKEND=supabase`, Node version) and for the `HEALTH_URL` secret. Screen paths, no secrets.
6. `tests/unit/headers.test.ts`: parses `public/_headers`; asserts the CSP has no `unsafe-eval`, `connect-src` includes supabase, `sw.js` is no-cache.
