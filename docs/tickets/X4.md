## Scope
1. **Start:** the Train tab / Start workout opens the **exercise picker** directly (no second START, no quiz first). Picker: search on top, **Recent** first, then all exercises grouped by kind; Create exercise at the bottom.
2. **Exercise view:** full-height set list grouped by exercise (row: set #, kg × reps, RPE if any, warm-up tag, PR badge in yellow). Swipe or ⋯ to edit/delete. The 46 px scroll box is gone.
3. **Input dock** pinned at the bottom: kg and reps Steppers (big numerals, visible step: 2.5 kg, or 5 kg for lower-body compounds per the existing "Big jumps" rule), prefilled from the last set; "Log set" primary; "Add RPE" reveals a compact 6–10 selector that fits 375 px; Warm-up toggle; "Next exercise".
4. **Rest timer:** ONE slim bar above the dock (remaining time, ±15 s, skip). Tap expands to a large view. Remove the duplicated timer node.
5. Header: elapsed time, set count ("5 sets", pluralised), **Finish** (hold 600 ms). "Screen may sleep" only when Wake Lock is unsupported or was denied.
6. Readiness (sleep/soreness/energy) becomes optional: one line on the summary ("How did it feel?"), not a gate.
7. **Summary:** per-exercise rows (sets, best set, PRs in yellow), total volume in kg, duration, an optional note, readiness → **Done returns to Today** (fixes the A2 dead end).
8. First sessions of a lift: a one-time note "Your first 2 sessions set the baseline. PRs start after that." instead of the bare "Baseline set."
9. Keep every existing behaviour: offline logging, PR detection/takeover (P4C), undo, hold-to-finish, session persistence across reloads.
