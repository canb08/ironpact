## Scope
1. `src/core/validate.ts`: zod 4 schemas mirroring the **DB checks** in `supabase/migrations/0001_schema.sql` for every writable row in `types.ts`, plus **UI-range** helpers per D14 (RPE 6–10 step 0.5, display name ≤16, etc.). Exercise label rules per E4.9 (`Run`/`Weight`/`MIN` rejected case-insensitively, no `·`, ≤24). A single `isWorldRecord(field, value)` used by the UI for "That's a world record. Check it."
2. `src/core/weeks.ts`: crew week = Monday 00:00 → Sunday 23:59:59 in the crew tz; `weekStartOf(localDate)` works on **dates**, never instants (E5.5); helpers to list a week's dates.
3. `src/core/credits.ts`: credits per E5.6's table (gym/run/martial session 1, MIN 0.5, cap **2.0 per local day**, a Floor `kind='min'` session never counts as a 1-credit session); `weekCredits(entries, weekStart)` → `{ credits, minCount, status: 'FULL' | 'HELD' | 'REST' }` per §2.2/§10.2.
4. `src/core/e1rm.ts`: Epley for r 1–12, `null` for r ≥ 13 or warm-ups; bodyweight lifts use logged bodyweight + added load when a bodyweight is known, else `null` (§7.1 cases).
5. `src/core/volume.ts`: tonnage of working sets (warm-ups excluded; bw lifts use added load only unless bodyweight given).
6. Tests in `tests/unit/core/*.test.ts` — everything §7.1 lists for these files, at minimum:
   - week containing Sun 25 Oct 2026 23:30 Amsterdam starts Mon 19 Oct; the 2027-03-28 switch;
   - credits: MIN 0.5, two sessions + MIN in a day cap at 2.0, Floor MIN session = 0.5 not 1;
   - e1RM at r=1, 12, 13; BW with and without bodyweight;
   - every zod schema accepts the edge values and rejects one-past-edge; E4.9 labels (U-X22).
   - **≥95% line coverage of `src/core/`** (configure `@vitest/coverage-v8` for `src/core/**` and `supabase/functions/_shared/**`, threshold enforced in `npm test`).
