## Scope
1. `src/ui/feel/feel.ts`: `feel(kind, opts?)` for `tick | set | plate | round | pr | lockout | error` per FEEL §3. 2. `src/platform/audio.ts`: add the cues the table needs that don't exist (`thud` for error, a weight-parameterised `clank`, a `lockout` slam), each ≤40 lines of WebAudio, lazy on first gesture. Keep existing cues and their tests.
3. `src/platform/haptics.ts`: add `tick`, `plate`, `round`, `lockout`, `error` patterns; iOS `switch` trick **on by default** (FEEL §3), `VITE_IOS_HAPTICS=off` stays as the off-switch.
4. `src/ui/ScrubDial.tsx` + `scrubdial.css`: vertical-drag numeral (pointer events, detents per `step`, a fast flick accelerates, `feel('tick')` per detent), `role="slider"` with aria-valuenow/min/max/text, arrow/PageUp/PageDown keys, tap → optional `onTapNumber` (keyboard fallback). Big Shoulders numerals. No layout animation.
5. `src/ui/motion/springs.css`: CSS custom properties with `linear()` spring easings derived from `springs.ts` UI/SLAM/HEAVY (+ a plain cubic-bezier fallback), so CSS motion uses the same springs.
6. Dev-only demo of every `feel()` kind + ScrubDial in `src/ui/DevUi.tsx` (not in the production bundle).
