## Scope
1. `supabase/functions/export/index.ts` (Deno, explicit `.ts` imports, no npm deps beyond `jsr:@supabase/supabase-js@2` pinned):
   - `GET`/`HEAD` only → else **405**. No CORS headers.
   - token from `Authorization: Bearer spx_…` **or** `X-Export-Token`; a `token` query param → **400**.
   - missing/malformed token (`^spx_[A-Za-z0-9_-]{43}$`) or unknown/revoked → constant **200 ms** wait then **401**, empty body.
   - `sha256hex(token)` lookup with the service-role client; atomic 1-hour rate-limit update exactly as §5.1 step 3; `> 60` → **429** + `Retry-After` seconds.
   - `since` per E0.1 (use `isValidSince` from the formatter) → **400** `bad since`; `format` ∈ lines|json|csv else **400**; default = `profiles.export_format`.
   - `user_id` **only** from the token row. Query that user's rows (`deleted_at is null`, plus the exercises they reference including soft-deleted ones) and call `formatExport`.
   - headers: `Content-Type` from `EXPORT_CONTENT_TYPE`, `Cache-Control: private, no-cache`, `ETag: "<sha256hex(body)>"`, `X-Content-Type-Options: nosniff`; `If-None-Match` match → **304** empty body.
   - set `last_used_at`; any unexpected error → **500** body `export failed`. **Never log the token or request headers.**
   - Put pure helpers (header parsing, status decisions, ETag) in `supabase/functions/_shared/export-http.ts` so they're unit-testable.
