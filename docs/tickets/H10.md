# H10 · Signed-in user on a fresh device gets stuck on "Start a crew" ("You're already in.")
**Lane:** C (owner's Codex) · **Model:** Codex · GPT-6.1 Sol, High · **Branch:** `H10-work` · **Starts after:** H9 merged (#63)

## Bug (found by the owner on iPhone, 2026-11-02, production)
1. Sign in in Safari and create a crew. 2. Add to Home Screen, open from the icon (iOS gives the installed app its own empty storage) and sign in again with the code. 3. The app shows `/crew/new`. Tapping create gives `copy.alreadyInCrew` ("You're already in.") and you can never reach the Floor.

Same thing for any second device, or after clearing site data.

**Cause:** `AuthGate` decides from `repo.q.myCrew()`, which reads only the local Dexie mirror (`src/data/repo.ts:137`). Right after sign-in on a fresh device the mirror is empty, so the gate sends you to `/crew/new`. When the first pull then lands the user's `crew_members` / `crews` rows, nothing re-runs the gate: it only re-runs on route changes and `userId` changes. `CrewSetupScreen` treats `already_in_crew` as a dead end.

## Scope
1. **Gate re-checks when crew data arrives:** while signed in without a crew, `AuthGate` re-runs its pass when the local crew membership changes (a Dexie `liveQuery` on `myCrew`, or the repo's existing pull-complete signal; use what exists, add nothing to the frozen contract unless unavoidable). A signed-in user whose first pull brings a crew is sent from `/crew/new` to `/` automatically.
2. **First pass on a fresh device waits briefly for the first pull:** if signed in and the local mirror has no crew, wait for the first pull to finish (cap 3 s; H9's cap still applies) before deciding `/crew/new`. Offline: decide immediately, as today.
3. **`already_in_crew` is never a dead end:** in `CrewSetupScreen`, on `already_in_crew` (create or redeem), trigger a pull and navigate to `/`. Keep showing `copy.alreadyInCrew` briefly only if the pull fails.
4. Tests:
    - Fresh device: signed in, empty mirror, the first pull adds membership → ends on `/`, never stuck on `/crew/new`.
    - Create returns `already_in_crew` → pull, then `/`.
    - Offline, no crew → `/crew/new` as before.
    - All H9 AuthGate tests stay green.
