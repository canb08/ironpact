## Scope
1. `supabase/config.toml` (from `supabase init`, project id `ironpact`). Add `[functions.export]`, `[functions.health]`, `[functions.push-dispatch]`, `[functions.rest-alarm]` with `verify_jwt = false` (§10 E3.5).
2. `supabase/migrations/0001_schema.sql`: **every table, column, check, default, index and FK in §4.3 as amended by §10.4/§10.5**. Including:
   - conventions: client-generated `uuid` PKs, `local_date date`, `client_updated_at`, `updated_at`, `deleted_at`, `created_at`;
   - triggers `set_updated_at`, `lww_guard` (per E4.5), `enforce_owner`, and the child-inherits-`local_date` trigger (D9: sets/cardio/martial/min rows take their session's `local_date`);
   - `profiles.export_format text not null default 'lines' check (export_format in ('lines','json','csv'))`;
   - ranges per §1.6 D14 / §4.0 D10 as the DB checks (wider safety nets than the UI);
   - exercise label rules per E4.9 (labels `Run`, `Weight`, `MIN` rejected; `·` forbidden; ≤ 24 chars);
   - `alter table … enable row level security` on **every** `public` table (policies come in A3; with RLS on and no policy, nothing is readable — that's correct for now).
3. `supabase/seed.sql`: ~60 global exercises (`owner_id` null) with `kind` (`lift`/`bw_lift`), `export_label`, compound/isolation flag (for rest defaults), and `exercise_muscles` rows. Common gym names only; no people.
4. `supabase/tests/schema.test.sql` (pgTAP): tables exist; every `public` table has RLS enabled (**fails CI if one doesn't**); key checks reject bad values (reps 0, RPE 5.25, bodyweight 301, label `Run`, label with `·`); `lww_guard` ignores an older `client_updated_at`; a set inserted into a session gets the session's `local_date` even when the client sent another; `updated_at` moves on update.
5. **CI:** add a `db` job to `.github/workflows/ci.yml` that installs the Supabase CLI (pinned version), runs `supabase db start` (or `supabase start -x` minimal services), applies migrations + seed, and runs `supabase test db`. Keep the existing `check` job unchanged.
6. `docs/DECISIONS.md`: append any §4.3-vs-§10 choices you had to make (one line each).
