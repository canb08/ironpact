## Scope (FEEL §4 "Muay Thai": read the class structure there first)
1. **Muay Thai only:** remove the other discipline chips and "Other" from `MartialForm`; always save `discipline: 'Muay Thai'`. Old entries with other disciplines still render as stored. Rename the "Fight" label to "Muay Thai" on Today's quick log and the Progress segment.
2. **Pad class mode** (lazy chunk; the default when you open Muay Thai): a setup screen (who strikes first, round length 3:00, reps 10/10, warm-up length or skip) → a pure, unit-tested state machine `padClass.ts`: warm-up → Half 1 *Punches* [striker A: combo 1..3, each `round 3:00 → push-ups/squats (tap Done)`] → **swap gear** card (tap Ready) → [striker B: combo 1..3] → **rest 2:00** with a gear reminder (long pads + belly pad) → Half 2 *Kicks* (same shape) → summary. Timestamps are based on `ends_at` like the rest timer, so backgrounding and locking the phone keep the right time.
3. **Round screen:** full-screen digits readable at 2 m, a banner in the striker's plate colour ("You strike · Punches · combo 2 of 3" / "<partner name> strikes · you hold"), `feel('round')` at round start/end, a double `tick` + edge pulse at 10 s, tap anywhere = pause, Wake Lock on.
4. **Combo notes:** on the push-up/squat screen, strike chips `1 2 3 4 5 6 Teep L kick R kick Knee Elbow` build a combo string like "1-2-R kick"; Skip in one tap.
5. **Summary + save:** minutes = elapsed, `rounds` = rounds you struck, plus rounds held and push-ups/squats shown; focus `Pads`; note = `Pads · <combos>` ≤120 chars, truncated at a combo boundary. Save → `feel('plate')`. Leave a `onSaved(entry)` hook that Y9 will use for the together/photo prompt.
6. **Bag / solo rounds:** a plain round timer (rounds × length, rest, bell).
7. **Quick log:** rounds `ScrubDial` × round-length chip (2/3/5 min) → minutes; focus chips **Pads · Bag · Clinch · Technique · Conditioning** (no Sparring); **Same as last class**.
8. **Combo book:** Progress → Muay Thai lists the jotted combos parsed from notes, newest first, with a drill count. This is read-only, built from existing entries.
